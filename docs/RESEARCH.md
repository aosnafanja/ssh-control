## 2. Функционал по продуктам

### 2.1 Termius (главный прямой конкурент)
Кроссплатформенный «современный» SSH-клиент с акцентом на синхронизацию и командную работу.
- **Встроенный SSH-терминал** (не запускает внешний терминал).
- **SSH key vault и agent** — хранение приватных ключей, генерация, использование через агент.
- **SFTP-клиент / файловый менеджер**.
- **Port forwarding / туннели** (local/remote/dynamic).
- **Snippets** — сохранённые команды для быстрого повторного использования.
- **Host chaining / jump hosts**, agent forwarding.
- **Сквозная зашифрованная синхронизация (AES-256, zero-knowledge)** между устройствами.
- **Team sharing** — общий доступ к хостам для команд.
- **Autocomplete (AI)** в платной версии.
- 2FA, секреты/пароли, биометрия на мобильных.
- По таблице SSHive: SSH ✅, SFTP ✅, туннели ✅, но **RDP/VNC/broadcast/AI-MCP отсутствуют**.

### 2.2 Royal TSX
«Швейцарский нож» для администрирования, заметно шире по протоколам.
- **Мультипротокол**: RDP, VNC, SSH/Telnet, Web (WebKit), FTP/SFTP/SCP, TeamViewer, VMware, Hyper-V, PowerShell и др.
- **Credential Management** — объекты учётных данных: назначение, переиспользование, наследование от папок.
- **Шифрование документов + парольная защита**, lockdown.
- **Безопасный командный доступ**: можно расшарить документ с подключениями, **не раскрывая личные учётные данные** (креды привязываются по имени).
- **Tasks**: Command Tasks и Key Sequence Tasks — автоматизация повторяющихся действий; токены подстановки.
- **Secure Gateway** — SSH-туннели (port forwarding), встроенные.
- **Dynamic Folders / Dynamic Credentials / RoyalJSON** — динамический импорт данных из внешних источников.
- **Интеграция с внешними хранилищами паролей**: 1Password, LastPass, KeePass.
- Кроссплатформенная совместимость документов между Royal TS / TSX / TSi / TSD.
- Шаблоны подключений, bulk-операции, AppleScript-скриптинг, тёмная тема, кастомные цвета/иконки вкладок.

### 2.3 SecureCRT (VanDyke)
Профессиональный терминал с сильной автоматизацией.
- **Богатая эмуляция терминалов**: VT100/102/220, TN3270, ANSI, SCO ANSI, Wyse, Xterm, Linux console.
- **Session Management**: вкладки, tab-группы, снапшоты (сохранённые рабочие пространства), клонирование сессий.
- **Credentials Management** — глобальные наборы учётных данных, на которые ссылаются сессии (удобно при регулярной смене паролей).
- **Keyword Highlighting** — подсветка слов/фраз/регэкспов (жирный, цвета, реверс).
- **Command Manager + Button Bar** — организация команд в именованные папки, запуск в 1 клик.
- **Скриптинг**: Python 3, VBScript, JScript, PerlScript; **script recorder** (запись нажатий в скрипт).
- **Port forwarding / data tunneling**.
- **Передача файлов**: SFTP, X/Y/Zmodem, Kermit, встроенный TFTP-сервер; интеграция с SecureFX (SCP/FTPS/WebDAV/S3).
- **Smart cards** X.509 (PIV/CAC), опциональные FIPS 140-2 шифры.
- RDP (только Windows), serial, Telnet/TLS.

### 2.4 Tabby (ранее Terminus)
Современный терминал-эмулятор с SSH, расширяемый плагинами.
- Встроенные **SSH/Telnet-клиент и менеджер подключений**; **serial-терминал**.
- **X11 и port forwarding**, **автоматическое управление jump-хостами**, agent forwarding (вкл. Pageant и Windows OpenSSH Agent).
- **Login scripts** (авто-команды при подключении).
- **Split panes**, темы и цветовые схемы, настраиваемые многоаккордные хоткеи.
- **Зашифрованный контейнер** для SSH-секретов и конфигурации.
- Передача файлов через **Zmodem**; поддержка PowerShell/WSL/Git-Bash/Cygwin.
- **Плагины**: SFTP-вкладка, синхронизация конфига в Gist/Gitee, quick-cmds, save-output, MCP-сервер и др.
- Веб-версия SSH/SFTP/Telnet (self-hosted).

### 2.5 electerm
Открытый терминал/файловый менеджер с широким охватом платформ и «современными» фичами.
- Клиент **SSH/SFTP/FTP/Telnet/Serial/RDP/VNC/Spice**.
- **Zmodem (rz/sz)** и **Trzsz (trz/tsz)**.
- **Туннели и connection hopping**.
- Аутентификация: publicKey, пароль, ssh agent, сертификаты, **OTP**, netbird и др.
- **Глобальный хоткей** для показа/скрытия окна (Quake-стиль).
- **Синхронизация** закладок в github/gitee secret gist, WebDAV, свой сервер, electerm cloud.
- **Quick commands / triggers**, quick/mirror input (рассылка ввода на все терминалы).
- **AI-ассистент + MCP-widget** (предложения команд, скрипты, агентный режим).
- Глубокие ссылки `ssh://`, `telnet://`; темы, фоновые картинки, прозрачность окна.

### 2.6 WindTerm
Бесплатный IDE-подобный SSH-воркспейс.
- **SSH/SFTP/Telnet/Serial + локальный shell** в одном окне.
- **IDE-подобное рабочее пространство**: вкладки, split-панели, дерево сессий, запоминание раскладки.
- **Умное автодополнение** команд и путей (учится на истории).
- **Встроенный SFTP-браузер** с drag-and-drop.
- **Менеджер сессий** — сворачиваемое дерево с папками и поиском.
- **Split & broadcast input** — ввод команды сразу на несколько серверов.
- **Поиск** по выводу, скроллбэку, истории и удалённым файлам.
- **Зашифрованное хранилище учётных данных (vault)**.
- **Auto-reconnect / keep-alive**.
- **Triggers & automation** — команды по событию подключения, по совпадению вывода, по расписанию.
- **Port forwarding** (local/remote/dynamic); **snippets / command sets**; **импорт OpenSSH config**; превью изображений/Sixel; Zmodem/Xmodem.

### 2.7 MobaXterm (Windows)
Windows-воркспейс «всё в одном», портативный.
- SSH, X11, RDP, VNC, FTP, SFTP, **Mosh**, Telnet, Rlogin, Serial, XDMCP.
- **Встроенный X-сервер** (X11-forwarding) — удалённые GUI-приложения рисуются локально.
- **Unix-команды на Windows**: bash, grep, awk, sed, rsync и др.
- **Графический SFTP-браузер** открывается при SSH-входе.
- Вкладки, макросы, менеджер сессий; **портативный единый exe**.
- Ограничения Home: 12 сессий, 2 туннеля, 4 макроса; Pro снимает лимиты и добавляет Customizer.

### 2.8 SSHive (macOS/iOS, нишевый «прямой» аналог)
- SSH, SFTP, RDP, VNC, туннели, **AI/MCP-интеграция**.
- **Интеграция с macOS Keychain**; Mac App Store; **iCloud-синхронизация** (Pro).
- **Broadcast mode**.
- Позиционируется как «всё в одном» с разовой покупкой, без подписки.

### 2.9 1Password for SSH (смежная категория — менеджер ключей)
Это не SSH-клиент, а эталон того, как можно управлять SSH-ключами.
- **Создание/генерация/импорт/хранение/синхронизация SSH-ключей** прямо в менеджере.
- **Встроенный SSH-агент** с авторизацией по **биометрии (Touch ID)**.
- **Подпись Git-коммитов** SSH-ключами.
- **Agent config** — порядок ключей, какие ключи доступны на машине.
- **Настройки авторизации**: как долго приложение «помнит» разрешение использовать ключ.
- **Watchtower** — поиск и импорт ключей с локального диска, оценка рисков.

## 4. Выводы: где SSH Control уже силён, а где отстаёт

### 4.1 Уникальные / редкие преимущества SSH Control
1. **Глубокое управление SSH-ключами как файлами**: переименование с автообновлением `IdentityFile` в `~/.ssh/config`, перемещение в Корзину. Такого нет ни у одного из рассмотренных конкурентов — они только читают/хранят ключи в своём vault.
2. **Прямое редактирование `~/.ssh/config` (алиасы Host)** и подключение одной командой `ssh alias` — это нативный, «прозрачный» подход без привязки к проприетарному хранилищу.
3. **Портативность** — всё хранилище в одной папке, легко бэкапить/переносить.
4. **Мастер-пароль с AES-256-GCM + scrypt** — современная криптография, сопоставимая с лучшими.

### 4.2 Ключевые пробелы (что есть почти у всех конкурентов)
Ранжировано по важности для пользователей и частоте встречаемости:

1. **Встроенный SSH-терминал.** Сейчас SSH Control лишь формирует команду и открывает Terminal.app. Все конкуренты имеют встроенный терминал — это самое частое ожидание от «SSH-клиента».
2. **SFTP-файловый менеджер.** Есть у Termius, Royal TSX, SecureCRT, electerm, WindTerm, SSHive. Очень ожидаемая пара к SSH.
3. **Туннели / port forwarding.** Есть почти у всех. Критично для доступа к внутренним сервисам.
4. **Snippets / сохранённые команды.** Экономия времени; есть у Termius, SecureCRT, electerm, WindTerm.
5. **Broadcast-ввод (одна команда на несколько серверов).** Есть у Royal TSX, SecureCRT, electerm, WindTerm, SSHive — ключевая фича для администрирования парка серверов.
6. **Синхронизация между устройствами.** У Termius (cloud), SSHive (iCloud), electerm (gist/webdav). У SSH Control — только ручной перенос папки.
7. **Автоматизация/скриптинг/триггеры.** У Royal TSX, SecureCRT, WindTerm, electerm.

### 4.3 Ниши, где можно дифференцироваться (менее занято)
- **AI/MCP-интеграция** — свежая волна (есть у electerm, SSHive, частично Tabby); у лидеров Termius/Royal TSX/SecureCRT её пока нет. Хорошая возможность выделиться.
- **Глубокая интеграция с macOS Keychain / Touch ID** для ключей (подход 1Password) — у большинства SSH-клиентов отсутствует.

## 5. Рекомендуемые приоритеты развития

Исходя из анализа, для SSH Control логична такая последовательность:

1. **Встроенный терминал** (быстрое подключение без внешнего Terminal.app) — закрывает главное ожидание.
2. **SFTP-файловый менеджер** рядом с терминалом.
3. **Snippets + broadcast-ввод** — дешёвые в реализации, но высоко ценимые фичи.
4. **Port forwarding / туннели** — расширяет сценарии с «храню серверы» до «работаю с инфраструктурой».
5. **Синхронизация** (iCloud/Keychain или зашифрованный файл в облаке) — сохраняя нынешнюю портативность.
6. **AI/автодополнение команд и MCP** — как дифференциатор на растущем тренде.

При этом стоит сохранить и подчёркивать как УТП: управление ключами как файлами, правку `~/.ssh/config`, портативность и локальную (без облака) модель данных.
