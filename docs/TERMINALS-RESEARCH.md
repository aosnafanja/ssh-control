# Исследование рынка: популярные терминалы, причины популярности и ценимые функции

> Второй этап исследования. Задача — понять, какие терминалы популярны у разработчиков, почему они популярны и какой функционал реально ценят пользователи. Это важно для решения SSH Control: добавить ли встроенный терминал и какими функциями он должен обладать.
>
> Дата: ноябрь 2026. Источники: опрос Stack Overflow 2025, официальные сайты и документация продуктов (ссылки в тексте).

---

## 1. Популярность терминалов: что показывает статистика

Самый репрезентативный источник — ежегодный опрос Stack Overflow Developer Survey. Разбивка по основному используемому терминалу среди профессиональных разработчиков (2025, данные на начало 2026):

| Терминал | Доля | Примечание |
|----------|------|------------|
| **Windows Terminal** | ~31% | лидер в абсолютном выражении, де-факто стандарт на Windows |
| **iTerm2** | ~22% | стандарт для опытных macOS-разработчиков |
| **Apple Terminal.app** | ~18% | дефолт macOS, чаще у новичков |
| **gnome-terminal / konsole / xterm** | ~14% (суммарно) | дефолты Linux |
| **Alacritty / kitty / WezTerm** | ~6% (суммарно) | «минималистичный GPU-ярус» |
| **Warp** | ~3% | крупнейший из «AI-терминалов», но всё ещё нишевый |
| Прочее (Ghostty, Wave и др.) | ~6% | длинный хвост, быстро фрагментируется |

Источник: [What Terminal Do Most Developers Actually Use in 2026](https://moltamp.com/blog/what-terminal-developers-use-2026/) (со ссылкой на Stack Overflow Developer Survey 2025).

**Два важных вывода из статистики:**
1. Большинство разработчиков **используют то, что поставляется с ОС**, и не меняют его (Windows Terminal, Terminal.app, gnome-terminal).
2. Длинный хвост (Ghostty, Wave, Warp, «AI-терминалы») **растёт быстрее всего** — по прогнозу, к 2026-му опросу их суммарная доля удвоится.

Дополнительный индикатор популярности — звёзды на GitHub (порядок величин на 2026): Windows Terminal ≈ 96k, Alacritty ≈ 55k, Hyper ≈ 43k, Ghostty ≈ 27k (очень быстрый рост после релиза в конце 2024), kitty ≈ 25k, WezTerm ≈ 17k. iTerm2 и Warp — проприетарные (Warp) или вне GitHub как основной хостинг (iTerm2).

## 2. Почему каждый терминал популярен и что в нём ценят

### 2.1 iTerm2 (macOS) — «золотой стандарт» на Mac
Популярен как замена штатному Terminal.app с огромной глубиной настройки и редкими фичами.

Ключевые ценимые функции ([документация iTerm2](https://iterm2.com/3.5/documentation-highlights.html)):
- **Split Panes** — деление вкладки на панели (cmd-d / cmd-shift-d), максимизация панели.
- **Hotkey Window** — окно, доступное по одному хоткею из любого места (Quake-стиль).
- **Умное выделение текста**: mouseless copy, Copy Mode, Smart Selection (автораспознавание URL/строк/email при квадроклике).
- **Regex-поиск** в выводе.
- **Autocomplete** по содержимому вкладки/скроллбэка.
- **Paste History** — история копирования/вставки.
- **Instant Replay** — «отмотка» экрана во времени, чтобы увидеть, что перезаписал `top`.
- **Triggers** — регэкспы с действиями (подсветка, алерт, отправка текста, захват вывода).
- **Shell Integration** — понимание промпта: навигация между командами, история, повторный запуск, скачивание/загрузка файлов с удалённых хостов.
- **tmux Integration** — tmux-окна как нативные вкладки.
- **Динамические профили** (JSON), **автопереключение профиля** (например, смена фона на продакшене).
- **Inline Images**, **Window Arrangements** (сохранение раскладок), **Undo Close**, **Password Manager (Keychain)**, **Timestamps**, **Open Quickly** (поиск по сессиям).
- 256-color и **24-bit truecolor**, smart cursor color, minimum contrast, notification center.

**Почему популярен:** глубина настройки + уникальные фичи (Instant Replay, Shell Integration, Triggers) + стабильность. Минус — сложность первичной настройки.

### 2.2 Windows Terminal — «современный дефолт Windows»
Популярен как бесплатная open-source замена устаревшей консоли, ставший стандартом Microsoft.

Ценимые функции:
- **GPU-ускоренный рендеринг** (DirectWrite), очень быстрый скролл.
- **Вкладки и панели (split)**, несколько профилей (PowerShell, CMD, WSL, Azure Cloud Shell) в одном окне.
- **Темы, шрифты, фоновые изображения, acrylic-блюр**, кастомные цветовые схемы.
- Полный **Unicode**, эмодзи, лигатуры.
- Настраиваемые **хоткеи**, JSON-конфиг, командная строка `wt`.
- Интеграция с WSL «из коробки».

**Почему популярен:** бесплатный, быстрый, современный, дефолтный и активно развиваемый Microsoft. Минус — привязка к Windows.

### 2.3 Ghostty — новый «фаворит минималистов»
Популярность взлетела сразу после релиза (дек 2024). Автор — Митчелл Хашимото (создатель HashiCorp).

Ценимые функции ([ghostty.org/docs/features](https://ghostty.org/docs/features)):
- **Нативный UI** на каждой платформе (macOS/Linux): окна, вкладки, сплиты на системных компонентах.
- **GPU-рендеринг** (Metal на macOS, OpenGL на Linux) — высокая скорость и корректность.
- **Сотни встроенных тем** + авто-переключение светлая/тёмная, свои темы.
- **Лигатуры** и управление font features.
- **Grapheme clustering** — корректный рендер эмодзи и RTL-скриптов.
- **Kitty graphics protocol** — картинки прямо в терминале.
- **Quick Terminal** — выпадающая панель под меню-баром.
- **AppleScript-автоматизация**, proxy icon, Quick Look, **Secure Keyboard Entry** (защита паролей от других процессов).

**Почему популярен:** «быстрый, корректный, нативный, не мешает» — идеален для запуска CLI-агентов (Claude Code, Codex). Его советуют как рациональный дефолт 2026 года. Минус — молодой, Windows пока в планах.

### 2.4 Alacritty / kitty / WezTerm — «GPU-минимализм» и мультиплексирование
Три близких по духу быстрых кроссплатформенных терминала; их выбирают за скорость.

- **Alacritty** (~55k звёзд): самый быстрый, GPU (OpenGL/Vulkan), **минимализм** — нет вкладок/сплитов (используют tmux), конфиг файлом. Ценят за «чистую» скорость и простоту.
- **kitty** (~25k): GPU-ускоренный, быстрый **и** функциональный — вкладки, сплиты, **layouts**, скрипты-«kittens», **graphics protocol**, remote control, лигатуры.
- **WezTerm** (~17k): GPU, **конфиг на Lua**, **встроенный мультиплексор** (аналог tmux «из коробки»), **SSH-интеграция** (`wezterm ssh`), serial, лигатуры.

**Почему популярны:** производительность и «полный контроль через конфиг». Минус — требуют ручной настройки, менее дружелюбны к новичкам.

### 2.5 Warp — «AI-терминал» как отдельная категория
Крупнейший представитель нового поколения AI-терминалов, ~3% рынка, но растёт.

Ценимые функции ([Toolradar: Warp](https://toolradar.com/tools/warp)):
- **Command blocks** — вывод группируется в визуальные блоки, удобная навигация.
- **AI**: объяснение команд, дебаг ошибок, предложение исправлений, smart-комплишены.
- **Team collaboration** — общие сессии и workflows.
- **Warp Drive** (объекты/команды), **Warp Agent**, темы, поиск.
- Написан на **Rust**, быстрый; IDE-подобный интерфейс.

Цены: Free, Build $20/мес, Business $50/юзер/мес, Max $200/мес. Рейтинг 4.4/5 (G2).
**Почему популярен:** интегрированный AI-опыт «из коробки». Минусы — **требует аккаунта**, сбор телеметрии, привязка к вендорскому AI.

### 2.6 Прочие и тренды
- **Hyper** (~43k): Electron-терминал, популярен за **плагины на JS** и темы, но медленный/тяжёлый.
- **Tabby / electerm / WindTerm** — уже разобраны в предыдущем отчёте (SSH-клиенты с встроенным терминалом).
- **Wave Terminal** — «максималистский» AI-воркспейс (чарты, превью файлов, чат).
- **MOLTamp и «skinnable shells»** — новая ниша «кастомных обёрток для CLI-агентов».

## 3. Синтез: что реально ценят пользователи в терминале

Объединяя статистику популярности и набор функций лидеров, получаем иерархию ценности:

### 3.1 «Гигиенический минимум» (без этого терминал не рассматривают)
1. **Скорость** — мгновенный ввод/скролл, GPU-рендеринг. Главный драйвер выбора Alacritty/kitty/WezTerm/Ghostty.
2. **Вкладки** — есть почти у всех.
3. **Split-панели / раскладки** — стандарт для работы с несколькими сессиями (iTerm2, Windows Terminal, kitty, WezTerm, Ghostty, Tabby).
4. **Темы и цвета** (включая truecolor/лигатуры) — эстетика и читаемость.
5. **Поиск по выводу** (в идеале с regex).

### 3.2 «Сильные дифференциаторы» (почему уходят с дефолтного терминала)
6. **Hotkey/Quake drop-down окно** — мгновенный доступ к терминалу из любого места (iTerm2, Ghostty, electerm).
7. **Shell Integration** — понимание промпта, история команд, скачивание/загрузка файлов, автопереключение профиля (фишка iTerm2).
8. **Мультиплексирование** — встроенный tmux или глубокая интеграция с tmux (WezTerm, iTerm2, kitty).
9. **Интеграция SSH** — встроенный SSH-клиент/менеджер (WezTerm, Tabby, electerm).
10. **Instant Replay / Triggers / автодополнение** — «power-user» фичи iTerm2.
11. **Расширяемость** — плагины (Hyper, Tabby) и скриптинг (iTerm2 AppleScript/Python, Ghostty AppleScript, WezTerm Lua).

### 3.3 «Новый тренд» (растущий запрос)
12. **AI-помощь** — объяснение команд, дебаг, агентный режим (Warp, electerm, Wave; iTerm2/Ghostty пока нет). Ключевой вектор 2025–2026.
13. **Хостинг CLI-агентов** (Claude Code, Codex, Gemini CLI) — терминал всё чаще оценивают по тому, насколько он «не мешает» агенту.
14. **Нативность и корректность** — Ghostty сделал это своим главным УТП.

## 4. Выводы для SSH Control

1. **Встроенный терминал — обязательный следующий шаг.** Сейчас SSH Control формирует команду и открывает Terminal.app. Все конкуренты из «гигиенического минимума» (вкладки, сплиты, темы, поиск, скорость) ожидаются по умолчанию.

2. **Минимально жизнеспособный терминал SSH Control** должен включать: вкладки, split-панели, поиск с regex, темы/цвета, hotkey-окно (Quake-стиль) — это дешёвые в реализации, но самые ценимые функции.

3. **Реалистичные дифференциаторы для ниши SSH Control:**
   - **Shell Integration в духе iTerm2** — но сфокусированная на SSH: автопереключение профиля по хосту/пользователю (цвет для продакшена), повторный запуск команд, быстрый SFTP.
   - **Глубокая связка «терминал + хранилище ключей/серверов»** — то, чего нет у iTerm2/Ghostty/Alacritty (они не управляют ключами и алиасами), но есть у SSH-клиентов (Tabby/electerm). Это прямое продолжение уже существующего УТП SSH Control.
   - **AI/автодополнение и MCP** — растущий тренд, пока отсутствующий у iTerm2/Ghostty/SecureCRT/Termius (в основном). Недорогой способ выделиться.

4. **Чего не стоит делать:** копировать Warp-модель с обязательным аккаунтом и телеметрией — аудитория SSH Control ценит локальность и портативность (это его текущее УТП, подтверждённое негативом к Warp).

**Итог:** чтобы двигаться к «SSH-клиенту с терминалом», достаточно закрыть гигиенический минимум (вкладки/сплиты/поиск/темы/hotkey) и добавить 1–2 дифференциатора из п. 3. Это уже поставит SSH Control в один ряд с Tabby/electerm, сохранив его сильные стороны — управление ключами и `~/.ssh/config`.
