# SSH Control

Настольное приложение для macOS — хранилище SSH-ключей и данных серверов в современном интерфейсе.

## Возможности

- **Ключи** — просмотр всех SSH-ключей из `~/.ssh` (тип, размер, отпечаток SHA256, публичный ключ, комментарий).
- **Создание ключа** — Ed25519 / RSA / ECDSA с парольной фразой и комментарием (через `ssh-keygen`).
- **Переименование ключа** — переименовывает файлы ключа и `.pub`, а также обновляет ссылки `IdentityFile` в `~/.ssh/config`.
- **Удаление** — перемещает ключ в Корзину.
- **Серверы** — хранение записей (название, группа, хост, порт, пользователь, способ входа: ключ/пароль, заметки, цвет).
- **Псевдонимы SSH** — управление записями `Host` из `~/.ssh/config`: создание, редактирование, удаление; затем подключение одной командой `ssh alias`.
- **Подключение** — кнопка «Подключиться» формирует команду `ssh` и открывает Terminal.app; есть копирование команды.
- **Безопасность** — опциональный мастер-пароль шифрует всё хранилище (AES-256-GCM, scrypt).
- **Переносимость** — все данные в одной папке, легко сделать резервную копию или перенести на другой Mac.

## Запуск

Нужен Node.js ≥ 18.

```bash
npm install          # один раз, установит Electron
npm start            # запуск приложения
```

> При первом запуске Electron скачивает свой бинарник (около 100 МБ). Если кэш npm содержит файлы с root-правами, задайте локальный кэш:
> `npm_config_cache="$PWD/.npm-cache" npm install`

## Где хранятся данные

По умолчанию всё хранится в папке **`~/SSH Control/`** (файл `data.json`). Папку можно изменить в настройках. Для переноса на другой Mac достаточно скопировать эту папку (и ввести мастер-пароль при первом открытии).

Сами ключи остаются в `~/.ssh` — приложение только читает их, создаёт и переименовывает по вашей команде.

## Сборка в `.app` / `.dmg`

```bash
npm run package   # папка .app в dist/
npm run dist      # .dmg и .zip в dist/
```

## Структура проекта

```
main/
  main.js               — точка входа Electron, IPC
  preload.js            — безопасный мост window.api
  services/
    keys.js             — скан/создание/переименование/удаление ключей
    sshConfig.js        — чтение/редактирование ~/.ssh/config (псевдонимы)
    storage.js          — портативное хранилище + шифрование
    connect.js          — команда ssh и запуск Terminal
renderer/
  index.html, styles.css, app.js — интерфейс
```
