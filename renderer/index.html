Безопасность

Пароль шифрует всё хранилище (AES-256-GCM). Без пароля данные восстановить невозможно.

Серверы и секреты хранятся в открытом виде.

Терминал

⌘D → Разделить вертикально (панели бок о бок)
⌘⇧D → Разделить горизонтально (стопкой)
⌘[ / ⌘] → Перейти к панели влево / вправо
⌘⌥← / ⌘⌥→ → То же (альтернатива)
⌘W → Закрыть активную панель (последняя — закрыть вкладку)
Enter → Следующее совпадение в поиске
Esc → Закрыть панель поиска / сниппетов / подсказки
⌘; → Подсказки автодополнения (открыть / скрыть)
↑ / ↓ → Выбрать подсказку, когда список открыт
Tab → Принять подсказку (иначе — дополнение оболочки)

Общие

⌘Q → Выйти из приложения
⌘C / ⌘V / ⌘X / ⌘A → Копировать / вставить / вырезать / выделить всё
⌘Z / ⌘⇧Z → Отменить / повторить
⌘M → Свернуть окно
Esc → Закрыть модалку
